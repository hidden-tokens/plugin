# Security policy

Please report a vulnerability privately. Do not open a public issue.

- Preferred: the "Report a vulnerability" button in the Security tab of this
  repository.
- Or write to info@hiddentokens.com with "SECURITY" in the subject.

Tell us the version, the steps to reproduce and the impact you see. Use
fictitious data only: never send real personal data.

We confirm receipt, keep you informed until a fix ships, and credit you in the
release notes if you wish. There is no bug bounty at this stage.

Scope: the code in this repository. The website, the desktop app and the
browser extension are reported the same way.
